# Pattanam Karikalan Catering & Event
### Chozha Arasu Bhojanam (Chola King's Feast)

A luxury, fully responsive frontend website designed for **Pattanam Karikalan Catering**, featuring the **Chola Dynasty** theme, authentic South Indian wedding catering showcase, and 1-tap WhatsApp booking.

---

## 🚀 Features

- **Chola Heritage Aesthetics:** Royal crimson, deep gold, and warm amber theme inspired by the Brihadisvara Temple gopuram architecture.
- **Both Mobile & Desktop Optimized:**
  - **Desktop:** Full panoramic hero section, interactive menu filter, elegant navigation bar.
  - **Mobile:** 1-tap Call and WhatsApp actions; responsive collapsible drawer menu.
- **Interactive Menu Showcase:** Category filtering for Traditional Elai Saapadu, Royal Biryani & Non-Veg, Wedding Buffets, and Live Dosa/Sweet counters.
- **1-Click WhatsApp Booking:** Direct pre-formatted WhatsApp booking ready to send directly to `+91 98945 79444`.
- **Ready for GitHub Pages:** Pure static HTML5, CSS3, and JavaScript — no build steps or server required.

## 🌐 How to Deploy to GitHub Pages

1. **Initialize Git & Push to GitHub:**
   ```bash
   git init
   git add .
   git commit -m "Initial commit for Karikalan Catering website"
   git branch -M main
   git remote add origin https://github.com/YOUR_USERNAME/karikalan-catering.git
   git push -u origin main
   ```

2. **Enable GitHub Pages:**
   - Go to your repository on GitHub.
   - Click **Settings** > **Pages** (under the "Code and automation" menu on the left).
   - Under **Build and deployment > Branch**, choose `main` and folder `/ (root)`.
   - Click **Save**.
   - Your website will be live in seconds at: `https://YOUR_USERNAME.github.io/karikalan-catering/`!
